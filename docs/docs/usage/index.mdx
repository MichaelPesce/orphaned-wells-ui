# Overview
Use OGRRE to upload documents, import extracted data, review records, and manage
access for your team.

- [OGRRE UI Usage](./ui.mdx): upload documents with a processor, review records,
  and export data.
- [Importing JSON/CSV records](./import_records.mdx): import existing data and add
  document images or a processor later.
- [Adding users to OGRRE](./add_users.mdx): add users and assign team and system roles.
- [Updating processor schema](./updating_processor_schema.mdx): maintain the fields
  used by a processor.
